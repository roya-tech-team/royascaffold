# Functional Requirements Template

For each `REQ-*`/`UC-*`:

- standard artifact metadata;
- source, rationale, priority;
- actor/preconditions/trigger;
- requirement statement and observable outcome;
- acceptance criteria including failures/edge cases;
- relations to capability, workflow, invariant, design/action, and tests;
- explicit out-of-scope/compatibility notes.

Requirements state **what/why**, not implementation steps.
