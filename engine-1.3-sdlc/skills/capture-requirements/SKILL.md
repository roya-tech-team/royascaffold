# Capture Requirements

- Inputs: sources/stakeholders, BRD/current requirements, requested outcome.
- Writes: business/requirements delta only.
- Required output: stable IDs, source/rationale/priority, acceptance criteria, actor/capability links, status.
- Do not design code or invent stakeholder decisions.
- Unknowns become questions/findings; gate on material meaning/scope.
