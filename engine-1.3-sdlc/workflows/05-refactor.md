# Refactor Workflow

1. Link requirements/contracts that must remain unchanged.
2. Capture characterization evidence before modification.
3. Design component/dependency/code-map after-state and state forbidden behavior changes.
4. Create reversible tasks and Context Packs.
5. Implement inside structural scope.
6. Run equivalence, regression, architecture, and changed-file checks.
7. Reconcile implementation/design records; requirements remain unchanged.

If behavior or public compatibility changes, return to the Change workflow.
