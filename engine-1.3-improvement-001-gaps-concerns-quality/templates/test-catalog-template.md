# Test and Evaluation Catalog Template

For each `TEST-*`: purpose/level, `CRIT-*`/requirements/invariants/NFRs, target
component/action/contract, replay method/command, environment/fixtures, expected result,
source/fingerprint scope, evidence artifact/retention, executor/adjudicator authority,
staleness inputs, runner unavailable/manual policy, owner, automation status, and
standard metadata.

Do not mark implementation `verified` when required tests/evidence are missing.
