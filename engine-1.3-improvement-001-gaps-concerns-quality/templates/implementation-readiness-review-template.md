# Implementation Readiness Review Template

Header: `REV-*` ID, change, reviewer/authority, timestamp, current SQR, and exact
execution/context input revisions.

For each task apply the consumer test: can another lower-capability implementer execute
from its Context Pack without choosing a material product, visual, content, contract,
architecture, or quality decision?

Check criterion/decision/reference/pattern trace, allowed paths, non-goals, dependencies,
foundation ordering, contradictions, stale inputs, observable checks/authority, adapter
provenance, relevance, and context budget. Disposition: `pass`,
`pass-with-conditions`, or `revise`; material invention, stale required inputs, open
blockers, or silent truncation cannot pass.
