# Reference Decision Record Template

Header: document/change/source identity, source fingerprint/location, purpose,
authority, rights/usage limits, owner, and status.

Separate observations (`FND-*`) from decisions. For every material `RDR-*` include
standard metadata plus Decision status, Materiality, Source aspect, Disposition
(`retain`, `adapt`, `reject`, `unresolved`), observed fact, interpretation, rationale,
confidence, unacceptable opposite, affected `DEC-*`/`CRIT-*`, and unresolved owner.

Use only applicable dimensions. Interface examples include composition, hierarchy,
density, scale, color, typography, motion, interaction, responsiveness, accessibility,
tone, and content. Non-visual sources may use behavior, contract, data, compatibility,
or operations.
