# Route Work

- Inputs: user outcome, profile, Main, active changes/status, supplied sources, affected
  boundaries, and adapter catalog.
- Writes: routing decision only; no canonical product changes.

Classify independently:

1. intent/workflow;
2. consequence: low/medium/high/critical;
3. uncertainty: low/medium/high;
4. judgment demand: low/medium/high;
5. reference, content/data credibility, novelty, reversibility, and ownership triggers;
6. artifact mode: compact/standard/rigorous;
7. candidate/selected/rejected adapters and conflicts;
8. required QDC/RDR/SQR/IRR, evidence, approval, and authority gates.

Output the reasons for every escalation and the next skill. Small file count cannot
lower high judgment. Block when project state, material intent, authority, or adapter
conflict cannot be resolved safely.
