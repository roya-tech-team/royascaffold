# Review Implementation Readiness

Inputs: current passed SQR, execution plan, task graph, planned/generated Context Packs,
selected adapter provenance, and reviewed source revisions.

For every task ask: can an implementer absent from discovery execute using this Context
Pack and declared repository access without material invention?

Check exact outcome/criterion/decision/reference/pattern inputs, allowed boundaries,
non-goals, dependencies, foundation ordering, contradictions, stale sources, observable
checks, authority, context relevance, and budget. Missing decisions return to their
owner; context defects return to compilation. Do not repair defects only in the review.

Create `REV-*` with `pass`, `pass-with-conditions`, or `revise`, reviewer authority,
exact inputs, findings, owners, and closure. `revise`, stale inputs, unresolved blocking
conditions, silent truncation, or required material invention blocks `ready`.
