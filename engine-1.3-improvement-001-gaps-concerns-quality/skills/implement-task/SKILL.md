# Implement Task

- Preconditions: change `ready`/`in-progress`, dependencies available, Context Pack fresh.
- Writes: task-allowed code/config/tests and task progress/evidence only.
- Follow exact outcome, QDC, RDR, pattern, adapter, non-goal, and evidence constraints.
- Missing/contradictory material product, visual, content, contract, architecture,
  migration, dependency, or security decisions stop and return to the owning phase.
  Do not improvise even when a plausible choice exists.
- New public behavior/contract/architecture/migration/dependency/security scope returns to analysis.
- Run task checks; report changed files, findings, incomplete work, and evidence references.
