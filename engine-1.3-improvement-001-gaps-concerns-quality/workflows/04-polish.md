# Polish Workflow

## Profiles

| Profile | Scope | Process |
|---------|-------|---------|
| Micro | copy, spacing, token-consistent local presentation | inherited/embedded QDC + compact reviews + targeted evidence |
| Interface | meaningful page/screen interaction/layout | QDC/RDR when referenced + experience/pattern delta + SQR/IRR |
| System | design system, navigation, global theme/cross-app behavior | rigorous normal Change subflow |

Visibility, authorization cues, navigation meaning, form behavior, validation, or data-meaning changes are not automatically polish.

Any discovered behavior/data/contract/security scope converts the change without discarding artifacts.

Polish code size does not imply low judgment. A supplied visual reference, subjective
quality target, new hierarchy, content realism decision, or global interaction may
route to standard/rigorous review. Translate references into durable retain/adapt/reject
decisions before implementation; screenshots verify those decisions afterward.
