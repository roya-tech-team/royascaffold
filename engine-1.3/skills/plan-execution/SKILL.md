# Plan Execution

Each task states goal, preconditions, exact input IDs, allowed paths, forbidden inventions, ordered steps, outputs, checks/evidence, done conditions, recovery, and handoff.

Split tasks when required context exceeds budget or outputs can be verified independently. The plan may not hide a design decision inside an implementation step.
