# Migrate Blueprint

1. Detect/inventory legacy layout and validity.
2. Map IDs/facts/history; classify conflicts/unknowns.
3. Build staged v1.3 tree; mark inference with evidence/confidence.
4. Validate/generate views and present create/move/retain/supersede/archive actions.
5. Apply only after approval with rollback manifest; never silently delete legacy knowledge.
