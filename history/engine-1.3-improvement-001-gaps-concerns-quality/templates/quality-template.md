# Quality Strategy Template

Include quality objectives/NFR links, test levels and responsibility, required commands/environments, traceability/coverage rules, architecture/contract/security/accessibility/performance checks, evidence retention/redaction/freshness, defect/debt policy, release gates, independent-review rules, and current gaps/accepted risks.

Separate first-implementation target from verified-final target. State which quality is
designed in QDC/SQR/IRR and which residual risks verification closes. For each material
criterion declare source/fingerprint scope, replay method, expected evidence, executor,
adjudicator authority, staleness inputs, and unavailable/manual policy.
