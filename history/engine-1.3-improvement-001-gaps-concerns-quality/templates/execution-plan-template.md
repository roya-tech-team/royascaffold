# Executable Task Plan Template

For every `TASK-*` include product outcome, task class (`foundation`/`optional`),
preconditions/dependencies, exact `CRIT-*`/`DEC-*`/`RDR-*`/`PAT-*` and component inputs,
allowed paths, selected adapter guidance/anti-patterns, non-goals/forbidden inventions,
ordered steps, expected outputs, exact observable checks/evidence/authority, context
tier, done conditions, escalation, failure/recovery, and handoff.

Plan header includes change/baseline/consequence/uncertainty/judgment, current SQR and
reviewed inputs, reviewers, assumptions/decisions, Context Manifest, foundation-before-
option graph, and rollout/migration/rollback requirements. If compilation reveals a
missing material decision, return to its owner; do not hide it in a step.
