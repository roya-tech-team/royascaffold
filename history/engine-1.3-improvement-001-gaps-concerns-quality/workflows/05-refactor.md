# Refactor Workflow

1. Link requirements/contracts that must remain unchanged.
2. Capture characterization evidence before modification.
3. Inherit the current QDC and record unchanged external criteria. Route judgment for
   any material pattern choice.
4. Design component/dependency/code-map after-state, explicit pattern/alternatives, and
   forbidden behavior changes. Run SQR when routed.
5. Compile reversible foundation-first tasks and Context Packs; use compact IRR unless
   consequence/judgment requires stronger review.
6. Implement inside structural scope.
7. Run equivalence, regression, architecture, changed-file, and evidence freshness checks.
8. Reconcile implementation/design records; requirements remain unchanged.

If behavior or public compatibility changes, return to the Change workflow.
