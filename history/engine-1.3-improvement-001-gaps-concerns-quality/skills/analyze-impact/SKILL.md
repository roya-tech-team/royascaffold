# Analyze Impact

- Inputs: request, canonical graph/index, code map, active claims, profile, selected
  adapters, current QDC/RDR/pattern/evidence records.
- Classify every layer and durable decision: changed, referenced, inherited,
  unchanged, stale, not-applicable.
- Output affected IDs/paths, consequence/uncertainty/judgment triggers, adapter
  prerequisites/conflicts, invalidated reviews/evidence, compatibility/migration/release
  effects, durable reconciliation owners, and unresolved material questions.
- Do not treat a search result as approval to widen scope.
