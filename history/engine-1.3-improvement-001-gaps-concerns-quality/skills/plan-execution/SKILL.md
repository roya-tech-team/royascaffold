# Plan Execution

Precondition: current SQR is `pass` or its non-blocking conditions are owned and carried
into the plan.

Each task states product outcome; class (`foundation` or `optional`); preconditions and
dependencies; exact `CRIT-*`, `DEC-*`, `RDR-*`, `PAT-*`, component and file inputs;
allowed paths; relevant adapter guidance and anti-patterns; forbidden inventions;
ordered steps; outputs; observable checks/evidence and authority; done conditions;
recovery; escalation; context tier; and handoff.

Build foundation tasks before optional breadth. Split when context exceeds budget or
outputs can be verified independently. Do not summarize away a `must` decision or hide
one inside an implementation step. If compilation exposes a missing decision, return
to its owner instead of inventing it.
