# Polish Workflow

## Profiles

| Profile | Scope | Process |
|---------|-------|---------|
| Micro | copy, spacing, token-consistent local presentation | compact change/task + targeted visual/accessibility evidence |
| Interface | meaningful page/screen interaction/layout | requirement/experience delta + interface component/action impact |
| System | design system, navigation, global theme/cross-app behavior | normal Change workflow |

Visibility, authorization cues, navigation meaning, form behavior, validation, or data-meaning changes are not automatically polish.

Any discovered behavior/data/contract/security scope converts the change without discarding artifacts.
