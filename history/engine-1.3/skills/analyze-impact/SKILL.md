# Analyze Impact

- Inputs: request, canonical graph/index, code map, active claims, profile.
- Classify every layer: changed, referenced, unchanged, not-applicable.
- Output: affected IDs/paths, risk triggers, dependencies/conflicts, migration/compatibility/release effects, unresolved questions.
- Do not treat a search result as approval to widen scope.
