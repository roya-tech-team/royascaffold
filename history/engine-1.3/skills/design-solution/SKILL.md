# Design Solution

- Inputs: requirement/workflow slice, profile/adapters, current architecture/data/contracts/components, NFRs.
- Writes: design and implementation-map delta; no code.
- Evaluate: boundaries, security/privacy, data/migration, contracts/compatibility, experience, components/actions, quality/operations.
- Output: decisions, after-state IDs/relations, alternatives/consequences, test/rollout needs.
- High-risk design requires independent relevant review.
