# Requirement Template

```yaml artifact
id: REQ-<MODULE>-<NN>
type: requirement
title: <observable outcome>
module: <module>
owner: <owner>
knowledge_status: draft
implementation_status: planned
constrained_by: []
realized_by: []
verified_by: []
```

Record actor, trigger, required outcome, rationale, preconditions, business rules, failure behavior, exclusions, priority, compatibility, and numbered acceptance criteria.
