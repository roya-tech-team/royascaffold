# ADR Template

Use `ADR-<datetime>-<slug>` with state `proposed`, `accepted`, `rejected`, `deprecated`, or `superseded`.

Sections: context/problem, decision drivers, considered alternatives, decision, positive/negative consequences, affected IDs, migration/rollout/rollback, owner/reviewers/date, superseding ADR.

Current architecture remains readable in `architecture/`; the ADR preserves why.
